UI/UX 设计 12 个技能

ui-ux-pro-max 设计

UI/UX 设计终极指南：50+ 样式、161 配色方案、57 字体搭配、99 条 UX 指南，覆盖 React/Next.js/Vue/SwiftUI 等 10 种技术栈。

📝 大白话：做界面设计时问它——怎么配色、怎么排版、什么风格最好看

web-design-guidelines 网页

网页界面设计指南，检查网页 UI 是否符合 Web 界面设计标准，包括无障碍、性能、响应式等。

📝 大白话：帮我检查网页 UI 有没有问题，合不合规

web-design-reviewer 审核

网页视觉设计审核，像设计师一样检查网站的视觉一致性、间距、层级、AI 痕迹等。

📝 大白话：像请了个设计总监来审核你的网页好不好看

sleek-design-mobile-apps 移动端

移动应用设计技能，专门为 iOS/Android 设计漂亮的移动应用界面。

📝 大白话：帮我设计一个好看的手机 App 界面

frontend-design 前端

前端设计技能，用 mager 签名风格生成和指导 UI 开发，产出生产级前端界面。

📝 大白话：帮我写前端代码，要求设计师级别的质量

design-md 设计系统

分析 Stitch 项目并合成语义化设计系统，生成 DESIGN.md 文件。

📝 大白话：帮我从设计稿生成设计系统文档

canvas-design 画布

在 PNG 和 PDF 文档中创建美丽的视觉艺术，适合做演示文稿和设计稿。

📝 大白话：帮我画一张好看的设计图或演示页

product-photography 摄影

AI 产品摄影，包含工作室灯光、场景图和包装图，适用于电商产品展示。

📝 大白话：帮我生成一张好看的产品展示图

arrange 布局

改进布局、间距和视觉节奏，修复单调的网格、不一致的间距和节奏问题。

📝 大白话：帮我调整一下页面的间距和布局，让它更整齐

typeset 排版

改进排版：修复字体选择、层级、大小、粗细和可读性，让文字更舒服。

📝 大白话：帮我优化页面的字体和排版

colorize 配色

为单调的设计添加战略性颜色，让界面更有视觉层次和吸引力。

📝 大白话：帮我给这个页面加点好看的颜色

bolder 增强

放大安全或平淡的设计，增加视觉趣味和刺激程度，让设计更有存在感。

📝 大白话：让这个设计看起来更大气、更有冲击力
💻
开发 & 工程 8 个技能

simplify 重构

审查变更代码，查找可复用、质量和效率问题，然后修复。保持代码简洁可读。

📝 大白话：帮我看看代码有没有可以简化的地方

investigate 调试

系统性调试，包含四个阶段：调查、分析、假设、修复。追查根本原因。

📝 大白话：帮我找出这个 bug 的根本原因

optimize 性能

诊断并修复 UI 性能问题：加载速度、渲染、动画、图片和打包优化。

📝 大白话：帮我优化这个页面的加载速度

extract 提取

提取并合并可复用组件、设计令牌和模式到设计系统中。

📝 大白话：帮我把重复的代码提取成通用组件

normalize 规范

审计并重新对齐 UI 以匹配设计系统标准、间距、令牌和模式。

📝 大白话：帮我把代码整理成符合设计系统的规范

harden 加固

通过更好的错误处理、i18n 支持、文本溢出处理提高界面健壮性。

📝 大白话：帮我让这个界面更健壮，减少崩溃

animate 动画

审查功能并添加有目的的动画、微交互和动效，提升用户体验。

📝 大白话：帮我给这个按钮加一些好看的动画效果

delight 惊喜

添加让人愉悦的时刻、个性和意想不到的 touches，让界面令人难忘。

📝 大白话：帮我加点有意思的小细节，让用户惊喜
🔍
代码审查 6 个技能

critique 批评

从 UX 角度评估设计，检查视觉层级、信息架构、可访问性、一致性等。

📝 大白话：请个 UX 专家来评价一下这个设计

plan-design-review 设计评审

交互式 CEO 和工程审查，评估每个设计维度，像 CEO 一样思考。

📝 大白话：像 CEO 一样评审这个设计方案可行不可行

plan-ceo-review 战略评审

CEO/创始人模式的计划审查：重新思考问题，找到 10 星产品，挑战前提。

📝 大白话：帮我看看这个产品想法有没有商业潜力

plan-eng-review 工程评审

工程经理模式的计划审查，锁定执行计划——架构、数据流、图表等。

📝 大白话：帮我评审一下技术实现方案靠不靠谱

codex 代码审查

OpenAI Codex CLI 包装器：代码审查、独立 diff 审查、代码质量评估。

📝 大白话：用 Codex 帮我审查代码质量

distill 精简

剥离不必要的复杂性，还原设计本质。伟大的设计是简单而强大。

📝 大白话：帮我简化这个复杂的设计，让它更简洁
🧪
测试 & QA 4 个技能

qa 测试

系统化 QA 测试 Web 应用并修复发现的 bug，迭代式测试和修复。

📝 大白话：帮我测试这个网站有没有 bug

qa-only 报告

只报告的 QA 测试，系统化测试 Web 应用并生成结构化报告。

📝 大白话：帮我生成一份测试报告，不用修 bug

audit 审计

运行技术质量检查：可访问性、性能、主题、响应式设计、动画等。

📝 大白话：帮我全面审计一下这个网站的技术质量

polish 抛光

最终质量检查：修复对齐、间距、一致性和微细节问题。

📝 大白话：帮我做最后的打磨，让细节更完美
📝
内容 & 创作 3 个技能

content-research-writer 写作

研究主题并撰写内容：博客文章、论文、推广文案等。

📝 大白话：帮我写一篇关于某个话题的文章

personalized-podcast 播客

根据提供的内容生成播客 episode，粘贴文本、指向本地文件或描述主题。

📝 大白话：帮我把这段内容变成一期播客

follow-builders 资讯

AI 构建者资讯——监控 X 和 YouTube 上顶尖 AI 构建者，整理内容。

📝 大白话：帮我追踪 AI 领域的最新动态和趋势
