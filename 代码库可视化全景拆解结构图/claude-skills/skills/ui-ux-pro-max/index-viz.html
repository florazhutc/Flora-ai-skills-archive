🏗️ 五层积木塔

这个系统像一栋五层的房子，每层有不同的功能。越往上越接近用户，越往下越底层。

第 5 层 · 入口
📖

技能入口层 (SKILL.md)

这本"说明书"的封面。告诉 AI 什么时候该用这个技能、怎么调用、有什么规则。AI 看到用户要做 UI/UX 相关的事，就会翻开这本书。

第 4 层 · 规则库
📋

快速参考层 (Rule Categories)

10 大类规则，按优先级排列。从最关键的无障碍（Accessibility）到最后的图表规范。每条规则都标注了"必须做"和"千万别做"。

第 3 层 · 数据库
🗄️

数据查询层 (data/*.csv)

8 个"藏经阁"。存着风格、配色、字体、图标、产品类型、UX 规范、图表类型、堆栈最佳实践。AI 不知道选什么颜色或字体时，就来这里查。

第 2 层 · 引擎
⚙️

搜索脚本层 (scripts/)

3 个"小机器人"。core.py 负责搜索，search.py 负责查询，design_system.py 负责生成设计系统。用户提需求，机器人去资料库找答案。

第 1 层 · 基础
🐍

运行时层 (Python)

这个系统的"引擎"。用 Python 写的，需要用户电脑上有 Python 才能跑。所有的搜索和计算都靠它。

⚡ 核心功能场景

这个工具能做什么？按重要程度排序，最常用的排在最前面。

1

🎯 一键生成设计系统

这是 UI/UX Pro Max 的核心超能力。你告诉它产品类型和风格关键词，它会自动生成完整的设计系统：设计模式、风格、颜色、字体、动效、还有要避免的坑。

python search.py "beauty spa wellness" --design-system → 输出完整的设计系统建议
2

🔍 按领域搜答案

针对某个具体问题单独搜索。比如想知道什么颜色适合 SaaS 产品、或者用什么图表显示趋势。

python search.py "minimal dark" --domain style → 返回 50+ 风格选项
3

📐 10 大规则类别

10 个"检查清单"，按优先级排序。排第一的是无障碍（Accessibility），然后是触摸交互、性能、风格选择、布局响应式、字体颜色、动画、表单反馈、导航、图表。

无障碍 → 颜色对比度 4.5:1、触摸区域 ≥44px、键盘导航...
4

📱 支持 10 种技术栈

不仅给设计建议，还给对应的代码实现建议。React、Next.js、Vue、Svelte、SwiftUI、React Native、Flutter、HTML+Tailwind、shadcn/ui、Angular。

python search.py "list performance" --stack react-native → 返回 RN 特定的性能优化
5

💾 设计系统持久化

生成的设计系统可以保存下来，下次继续用。还能按页面做个性化调整。

python search.py "fintech" --design-system --persist -p "MyApp" → 保存到 design-system/
6

🔄 输出多种格式

可以输出终端显示的 ASCII 格式，也可以输出 Markdown 格式方便写文档。

python search.py "vibrant" --design-system -f markdown
7

✅ 交付前检查清单

做完后还有一套"质检"流程。检查无障碍、对比度、动画、暗色模式、响应式等。

运行 --domain ux 快速验证一遍
8

🧠 智能推理

不仅搜结果，还会根据产品类型自动推理。输入"音乐播放器"，会自动推荐适合的风格和颜色。

基于 ui-reasoning.csv 里的规则自动匹配

📚 大白话百科

这些词儿到底什么意思？用日常例子讲给你听。

Design System（设计系统）
像"装修风格指南"。告诉你墙面用什么颜色、地板用什么材质、门把手用什么样式——一套完整的设计规则。
Glassmorphism（玻璃拟态）
像"磨砂玻璃"。界面元素像磨砂玻璃一样半透明模糊，背景模糊可见，常见于苹果和现代设计。
Bento Grid（便当盒布局）
像"便当盒"。把界面分成一个个规则的小格子，像日式便当盒一样整整齐齐。
Accessibility（无障碍）
像"斜坡和扶手"。让残障人士也能使用产品——屏幕阅读器能读、颜色对比够高、键盘能操作。
CLS (Cumulative Layout Shift)
像"地震"。页面加载时东西突然乱跳——图片没留位置、字体突然加载把内容推开。搜索引擎会扣分。
4.5:1 对比度
像"黑底白字"。文字和背景颜色差别够大，即使视力不好也能看清。这是 WCAG 标准。
Reduced Motion
像"减少晃动"。有些用户不喜欢动画（会头晕），系统设置里可以关闭，界面要配合支持。
Safe Area（安全区域）
像"不越界"。手机屏幕上有刘海、灵动岛、底部手势条，界面不能被它们挡住。
