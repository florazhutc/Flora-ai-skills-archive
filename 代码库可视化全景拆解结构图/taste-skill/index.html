使用判断

适合谁

前端设计：适合让 Codex 生成更有视觉品味、更少模板感的页面。

Codex 用法

优先按具体技能或原项目安装方式使用，不建议把归档目录整包复制。

npx skills add https://github.com/Leonxlnx/taste-skill

许可证 / 风险

查看原仓库；安装前核对具体版本与 license。

从哪个开始

gpt-taste 适合 Codex/GPT；redesign-existing-projects 适合改已有项目；minimalist-ui 适合干净产品页；industrial-brutalist-ui 适合强风格实验。

三个控制旋钮

DESIGN_VARIANCE 控制布局实验性；MOTION_INTENSITY 控制动效强度；VISUAL_DENSITY 控制信息密度。先设中等，再根据截图调高或调低。

推荐提示

要求模型先生成视觉方向，再实现页面，并在完成后用截图检查移动端、文本溢出和 hover/focus 状态。

九大技能

每种技能针对不同的设计场景，选择最适合你的

taste-skill 推荐

默认全能型技能。想输出高端前端代码又不想限定具体风格时使用。最安全的选择。

📝 大白话：不知道选哪个时就选它，不会出错

gpt-taste 强力版

更严格、更有主见的版本。适合 GPT/Codex 模型，更强的 GSAP 动画方向，更激进的反 AI slop 规则。

📝 大白话：给 AI 戴上"设计总监"的帽子，听话

images-taste-skill 看图

图片优先工作流：生成设计图 → 深入分析 → 精准实现。当视觉质量是主要挑战时使用。

📝 大白话：先画图，再照着图写代码

redesign-skill 重构

用于已有项目的改进。先审计当前 UI，然后修复薄弱的布局、间距、层级和样式决策。

📝 大白话：像请了个设计顾问来优化现有界面

soft-skill 柔和

制作精致、安静、看起来很贵的高端界面。更柔和的对比度、更多留声、高级字体、弹簧动画。

📝 大白话：苹果式简约高端风格

minimalist-skill 极简

更干净的编辑类产品 UI，灵感来自 Notion 或 Linear。保持克制的配色和清晰的结构。

📝 大白话：像 Notion、Linear 那样的性冷淡风

brutalist-skill BETA

更硬朗的机械视觉语言：瑞士字体、锐利对比、原始结构、实验性构图。

📝 大白话：粗犷、工业、原始美感

stitch-skill Google

使用 Google Stitch 兼容的语义设计规则，包括额外的 DESIGN.md 导出格式。

📝 大白话：如果你用 Google Stitch，选这个

output-skill 防懒

当 AI 太懒时使用。推动完整输出、无占位注释、不跳过实现步骤。

📝 大白话：防止 AI 偷懒，留一堆 TODO

🎛️ 三档参数调节

taste-skill 有三个可调节的参数，根据你要做的项目调整（1-10）

DESIGN_VARIANCE

布局实验程度

1-3: 简洁居中 8-10: 先锋不对称

MOTION_INTENSITY

动画强度

1-3: 简单悬停 8-10: 磁性/滚动触发

VISUAL_DENSITY

视觉密度

1-3: 宽松奢华 8-10: 密集仪表盘

🏗️ 技能层级架构

从基础到高级，9 种技能的分层关系

🎯 taste-skill / gpt-taste

默认全能型技能。所有其他技能的基础包，提供核心设计规则和反 AI slop 原则。

  • 高端设计原则
  • 字体搭配规则
  • 动画过渡系统
↓

🎨 soft-skill / minimalist-skill / brutalist-skill

基于 taste-skill 的风格变体，专门针对不同设计方向。

  • soft: 苹果式高端简约
  • minimalist: Notion/Linear 性冷淡
  • brutalist: 粗犷工业风
↓

🔧 redesign-skill / images-taste-skill / output-skill

特定场景专用技能，处理具体问题。

  • redesign: 现有项目优化
  • images: 看图生成代码
  • output: 防止 AI 偷懒
↓

🔗 stitch-skill

Google Stitch 平台专用适配层，包含 DESIGN.md 导出规则。

  • Stitch 语义设计规则
  • 设计系统导出

💬 假如 Taste Skill 是一个设计团队

👨‍💻

Hey，我想做一个很酷的 Landing Page，能帮我生成前端代码吗？

🎨

我是 taste-skill！没问题，你想要什么风格？

👨‍💻

想要那种看起来很高级、很有质感的设计，不要那种 AI 生成的低质量界面。

✨

收到！让我开启「高端模式」—— 适当的留白、精心设计的排版、细腻的动画过渡。不是那种模板化的"AI slop"。

👨‍💻

太好了！再帮我加点动画，让页面动起来。

🎬

没问题！我会加上：按钮悬停的微妙缩放、滚动时的淡入效果、卡片hover的提升感。不会太过，恰到好处的高级感。

👨‍💻

对了，我还有个现有项目 UI 很差，能帮我优化吗？

🔧

我是 redesign-skill！先审计现有 UI 的问题：布局是否合理？间距是否统一？视觉层级是否清晰？然后对症下药优化。

Taste Skill 改变了什么？

❌ 没有 Taste Skill

✗ 通用的蓝色按钮
✗ 平平无奇的卡片布局
✗ 毫无生气的静态界面
✗ 随机选择的系统字体
✗ 没有视觉层次

✅ 有 Taste Skill

✓ 精心设计的主色调按钮
✓ 有层次感的卡片组合
✓ 流畅的交互动画
✓ 搭配合理的高端字体
✓ 清晰的视觉引导
