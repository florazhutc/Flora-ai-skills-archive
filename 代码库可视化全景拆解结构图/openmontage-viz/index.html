适合谁

视频团队 / 内容创作者 / Agent 工程师：适合需要把研究、脚本、素材、剪辑和渲染串成可审计生产流程的人。

Codex 用法

它不是单个可安装 Skill。克隆项目后在 Codex 中打开仓库，让 Agent 先选流水线、读清单，再进入制作。

git clone https://github.com/calesthio/OpenMontage.git && cd OpenMontage && make setup

许可证 / 风险

AGPL-3.0。运行需要 Python 3.10+、Node.js 18+ 和 FFmpeg；云端生成服务可能产生费用，外部素材仍需核对授权范围。

Agentic video production system

OpenMontage

把 AI 编程助手变成一支完整的视频制作团队：先研究和提案，再写脚本、规划场景、生成或检索素材、剪辑合成，最后通过质量关卡交付。

系统架构

所有流水线共享一条可恢复的生产主线。Agent 读取结构化清单和阶段导演技能，在每个创意决策点保留人工审批，并把成本、选择和状态写入检查点。

01Research

检索当前资料、受众问题和视觉参考。

02Proposal

提出差异化概念、工具路径和成本预估。

03Script

写脚本、旁白和信息节奏。

04Scene Plan

把脚本拆成镜头、画面和时间线。

05Assets

生成或检索影像、语音、音乐和图形。

06Edit

筛选素材、安排节奏、混音和字幕。

07Compose

渲染成片并执行画面、音频与交付审查。

Pipeline YAML

规定阶段、允许使用的工具、产物格式和成功关卡。

Director Skills

它像怎样的视频团队？

关键不是一次性生成，而是把模糊要求逐步变成可审批、可计价、可恢复的生产计划。

你这是一个我喜欢的 YouTube Short。保留它的节奏和钩子，但改成 45 秒的量子计算解说。
OpenMontage Agent我会先分析转录、场景、关键帧和视觉风格，然后给你 3 个原创方向。现在只做研究和提案，不生成付费资产。
OpenMontage Agent方向 B 最适合：Animated Explainer 流水线，Remotion 合成，Piper 旁白可实现零密钥版本。若改用云端图像，预计成本约为……
你批准方向 B，但画面只用开放档案和动态图形。
OpenMontage Agent约束已写入场景计划。下一步会先提交逐场景素材板供你确认，再进入最终渲染和质量检查。

这段流程展示了 OpenMontage 的核心差异：参考驱动、先提案后花费、明确人工关卡，并把工具选择与约束写入可审计的生产状态。

大白话解释

把它看成“视频制作操作系统”比“视频生成模型”更准确。

它到底是什么？

一套让 Codex、Claude Code、Cursor 等 AI 编程助手按真实制作流程工作的仓库。Agent 是制片与导演，流水线是生产制度，工具负责具体执行。

和文生视频有什么不同？

文生视频模型通常只负责生成一个片段；OpenMontage 还负责前期研究、脚本、选材、剪辑、合成、字幕、音频和交付审查。

为什么零密钥也能做视频？

因为它可以用 Piper 配音、开放档案提供真实动态素材、Remotion 或 HyperFrames 合成，再由 FFmpeg 完成后期。零密钥路径不依赖付费视频模型。

什么时候不适合？

如果只想快速生成一个独立镜头，直接调用视频模型更轻。OpenMontage 更适合需要多阶段控制、可追踪成本、人工审批和最终成片的任务。
