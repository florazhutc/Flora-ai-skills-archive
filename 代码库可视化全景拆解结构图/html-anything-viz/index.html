📚 大白话解释

HTML Anything 是什么？ 一个给 AI 程序员用的 HTML 编辑器。它的特点是"本地优先"——不需要服务器，不联网也能用，也不需要你配置任何 API Key。

怎么个工作？ 集成了 75 套现成的 HTML 技能模板，你告诉它要做什么（做个海报、简历、图表），它自动生成对应的 HTML 代码。

支持哪些 AI 工具？ 8 种主流 coding-agent CLI 都能自动识别，包括 Claude Code、Cursor、Copilot、Qwen Coder 等。

为什么叫"可交付"？ 它生成的不仅是代码，而是一个可以直接用的成品：可以导出 PDF、发小红书、做成演示文稿。
